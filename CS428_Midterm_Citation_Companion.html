How the exam is graded (from the review slides)

  • Format: 5 questions × 25 pts. Each question likely asks for five numbered items (#1–#5) with explanation and citation, so each item is worth 5 pts. Open book/note/device/AI, except the last question has no AI. 4-hour limit once started.
  • Per item: 0 missing · 1–2 irrelevant · 3 vague citation (“Brooks, chapter 2”) or no citation · 4 = brief correct answer + specific citation (1–2 sentences) · 5 = 3–5 sentences of real detail + correct citation. Up to 5 extra-credit points overall.
  • Citations: must identify exactly what you rely on (book + chapter/fact number + title; article title + date; slide number). If a point just restates a class source, cite the source, not the slide.
  • AI: name the tool and paste the exact prompt you used. Write answers in a local editor first, then paste into Learning Suite.
  • Winning pattern (slide 8): Risk/Mitigation label → why it matters in this scenario → concrete mitigation → “See [source].”
Answer template: “#1. Risk: … In this scenario … A mitigation is … See Brooks, TMMM, Ch. 2 (“The Mythical Man-Month”), Brooks’s Law.”
